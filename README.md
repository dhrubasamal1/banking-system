# Simple Banking System

## Overview
The Code for the Banking system is written in Python that simulates fundamental banking operations. It features a persistent runtime environment that allows users to create new accounts, securely log in using a 4-digit PIN, and perform standard financial transactions (deposits and withdrawals) while preventing overdrafts.

## Prerequisites
- **Python 3.1** or above versions must be installed on the system.
- No external libraries or dependencies are required. This project relies entirely on the Python Standard Library.
